# Agent Instructions for Sway Project

## Projektregler & Retningslinjer

1. **Manuel ændring:** 
   Som udgangspunkt viser du kun implementationen af koden i chatten og laver kun direkte kodeændringer i projektet, når jeg beder om det.

2. **Ændringer:** 
   Ændr ELLER opret ALDRIG filer uden at spørge mig om lov og forklare ændringen først.

3. **Arkitektur:** 
   Følg primært MVVM-mønsteret med Jetpack Compose i UI (Material 3), og brug headless C++ JUCE til DSP / lydmotoren.

4. **Byg:** 
   Kør aldrig automatisk `gradle_build` eller andre bygge-kommandoer uden at jeg beder om det.
